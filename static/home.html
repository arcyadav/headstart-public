HeadStart

A study planner for your semester. Give it your classes, exams, tasks and free time, and it plans when to study each thing so deadlines are met, and re-plans as you go.

Try the demo

Set up a semester, add subjects, exams and tasks, and watch it plan. The demo is shared and isn't kept: Reset wipes it, and it starts blank again whenever the server restarts.

Open the demo

Use it for real, on your computer

Recommended: HeadStart is free and open source. Run it on your own computer and your planner stays there; nothing is sent anywhere.

Get it on GitHub

Set it up on your computer

You need Python 3.12 and Git. Then, in a terminal:

git clone https://github.com/arcyadav/headstart-public.git
cd headstart-public
python -m venv .venv
.venv\Scripts\activate        (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python app.py

Then open http://localhost:5000. Next time, open a terminal in that folder and run just the activate line and python app.py. Your planner is kept in the data folder.

What it does

  • Plans study sessions into the free time you paint on a weekly grid, within your daily study limits.
  • Adds a lecture to study after each class, and revision before each exam.
  • Finishes work before its deadline, in sensible session lengths with breaks, and tells you when something can't fit.
  • Re-plans whenever you log a session, mark a task done or a class is cancelled, keeping the rest of the plan stable.
